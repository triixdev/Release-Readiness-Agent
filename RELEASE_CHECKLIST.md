# Release Checklist

Use this file to define what "ready to ship" means for this project.
Each item below is validated automatically by the Release Readiness Agent.

## Checks

- [ ] **tests_pass** — All tests must pass
- [ ] **no_todos** — No TODO or FIXME comments in changed files
- [ ] **changelog_updated** — CHANGELOG.md must be updated
- [ ] **no_unreviewed_migrations** — No unreviewed database migration files
